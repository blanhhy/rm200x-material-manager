覆盖全面然鹅并没有什么用的素材管理
> 唯一的用处是清理没用到的素材（×）

## Setup

```bash
git clone https://github.com/blanhhy/rm200x-material-manager.git
cd rm200x-material-manager
npm install
npm run dev
```

也提供了 [在线示例](https://blanhhy.github.io/rm200x-material-manager/)
